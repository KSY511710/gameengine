# Smash Color

**Smash Color** is a high-speed action puzzle game developed with **Unreal Engine 5.6**.
The player must strategically swap colors to destroy obstacles, manage stamina, and escape the city within a time limit.

---

## 🛠 Development Environment

* **Engine Version**: Unreal Engine 5.6
* **Platform**: Windows 10 (64-bit)

## 🚀 Installation & How to Run

1. Download and extract the game files (`.zip`).
2. Navigate to the extracted folder.
3. Double-click **`SmashColor.exe`** to launch the game.
   > **Note:** No internet connection is required to play.

## 🎮 Controls

| Key / Button | Action | Description |
| :--- | :--- | :--- |
| **Left / Right Arrow** (`←`, `→`) | Move | Move the character left or right. |
| **Left Mouse Button** (`LMB`) | Dash | Perform a quick dash to gain speed. |
| **Right Mouse Button** (`RMB`) | Swap Color | Switch character color (**Red** ↔ **Blue**). |

## 🎯 Gameplay & Intended Play Order

The primary goal is to escape the map by collecting **Green Gems** hidden throughout the city.

### 1. Color Matching Mechanics
* **Blue Objects**: Destroy them to replenish your **Red Stamina**.
* **Red Objects (Enemies)**: Use Red Stamina to destroy them.

### 2. Objectives
* Explore the map and collect at least **10 Green Gems**.
* Maintain high speed to survive, but be careful of collisions.

### 3. Extraction
* Once the gems are collected, proceed to the **Exit Point** to clear the stage.

## ⚠️ Known Issues / Limitations

* **Enemy AI Freeze**: Occasionally, enemy objects may collide with obstacles and stop moving or freeze in place. Please be cautious of stationary enemies during high-speed runs.
